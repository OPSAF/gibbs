Gibbs Studio 操作文档

详细说明 Gibbs 采样算法的计算原理、参数含义和使用方法

简介 算法原理 参数说明 分布详解 使用示例

1. 简介

Gibbs Studio 是一个交互式的 Gibbs 采样可视化工具，用于展示马尔可夫链蒙特卡洛（MCMC）方法在高维后验推断中的应用。

1.1 什么是 Gibbs 采样？

Gibbs 采样是 MCMC 中最常用的算法之一，它通过在给定其他变量值的条件下，依次从每个变量的条件分布中采样来生成样本。这使得我们能够从复杂的高维联合分布中抽取样本，即使这个分布没有解析形式。

1.2 核心思想

对于一个 d 维的联合分布 p(X₁, X₂, ..., X_d)，Gibbs 采样通过迭代地从条件分布 p(X_i | X₁,...,X_{i-1}, X_{i+1},...,X_d) 中采样，最终生成一个收敛到目标分布的马尔可夫链。

2. 算法原理

2.1 Gibbs 采样步骤

  1. 初始化状态向量 X⁽⁰⁾ = (X₁⁽⁰⁾, X₂⁽⁰⁾, X₃⁽⁰⁾)
  2. 对于每个迭代 t = 1, 2, ..., N：
    • 从 p(X₁ | X₂⁽ᵗ⁻¹⁾, X₃⁽ᵗ⁻¹⁾) 采样 X₁⁽ᵗ⁾
    • 从 p(X₂ | X₁⁽ᵗ⁾, X₃⁽ᵗ⁻¹⁾) 采样 X₂⁽ᵗ⁾
    • 从 p(X₃ | X₁⁽ᵗ⁾, X₂⁽ᵗ⁾) 采样 X₃⁽ᵗ⁾
  3. 收集样本 X⁽ᵗ⁾（跳过 burn-in 期后）

2.2 条件分布的构建

在 Gibbs Studio 中，每个变量的条件分布由两部分组成：

Xᵢ | Xⱼ (j≠i) ~ Distribution(location, scale)

其中：

location = Σ (coefficientⱼ × Xⱼ) (j ≠ i)

即条件均值（location）是其他变量的线性组合。

提示： 系数决定了变量之间的条件依赖强度。正系数表示正相关，负系数表示负相关，系数绝对值越大表示依赖越强。

2.3 收敛诊断指标

为了判断链是否收敛，我们计算以下指标：

  • ESS（有效样本量）：衡量样本的独立程度
  • 自相关系数：衡量样本间的相关性衰减速度
  • 相关矩阵：衡量变量间的线性关系
  • 5%-95% 区间：展示样本的分布范围

3. 参数说明

3.1 参数面板布局

每个变量（X、Y、Z）都有独立的配置块，包含：

参数 符号 说明 作用
Y 系数 / Z 系数 β 条件分布的回归系数 控制其他变量对当前变量的影响强度
尺度 / 标准差 σ 条件分布的尺度参数 控制采样值的波动范围
条件分布 - 条件分布类型 决定采样值的概率分布形态

3.2 Location（条件均值）的计算

对于三元变量系统，每个变量的条件均值（location）计算方式如下：

location_X = β_XY × Y + β_XZ × Z
location_Y = β_YX × X + β_YZ × Z
location_Z = β_ZX × X + β_ZY × Y
注意： location 是一个动态值，每次迭代时会根据其他变量的当前值重新计算。

3.3 Scale（尺度参数）的作用

Scale 参数控制采样值的波动程度：

  • 小 scale（0.3-0.7）：采样值集中在 location 附近
  • 中等 scale（0.7-1.2）：正常波动
  • 大 scale（>1.2）：采样值分散，链混合更快但波动更大

3.4 MCMC 设置参数

参数 说明 推荐值
初始向量 链的起始点 接近目标分布的均值
迭代样本数 总采样次数（含 burn-in） 5000-10000
Burn-in 丢弃的初始样本数 500-1000（约10%）
Thinning 采样间隔（减少自相关） 1-3
随机种子 控制随机性，便于复现 任意整数或留空

4. 分布详解

每种分布的 location 和 scale 参数作用略有不同：

正态分布 Normal 连续

高斯分布，对称钟形曲线。最常用的条件分布。

f(x) = (1/√(2πσ²)) × exp(-(x-μ)²/(2σ²))
参数作用
location分布均值 μ
scale标准差 σ
适合作为默认选择，生成平滑、对称的样本。
均匀分布 Uniform 连续

在区间 [μ-σ, μ+σ] 内均匀采样。

f(x) = 1/(2σ) for x ∈ [μ-σ, μ+σ]
参数作用
location区间中心 μ
scale半区间宽度（区间 = μ ± σ）
样本在区间边界处概率密度最高，中间最低。
拉普拉斯分布 Laplace 连续

双指数分布，比正态分布有更厚的尾部。

f(x) = (1/(2b)) × exp(-|x-μ|/b)
参数作用
location分布峰值 μ（也是均值和中位数）
scale尺度参数 b，控制尾部厚度
会产生更多极端值，适合模拟跳跃行为。
学生 t 分布 Student-t 连续

厚尾分布，自由度较低时尾部更厚。

f(x) ∝ (1 + x²/ν)^(-(ν+1)/2)
参数作用
location分布中心 μ
scale影响自由度（df = 2 + 4×scale）
对异常值有较好的鲁棒性，scale 越大自由度越高（越接近正态）。
逻辑斯蒂分布 Logistic 连续

S 型分布，尾部比正态稍厚。

f(x) = exp(-(x-μ)/s) / (s(1+exp(-(x-μ)/s))²)
参数作用
location分布中位数 μ
scale尺度参数 s，控制分布宽度
累积分布函数是逻辑函数，常用于建模概率。
三角分布 Triangular 连续

三角形分布，在 location 处概率最高。

f(x) = 2(x-a)/(b-a)(c-a) for a ≤ x ≤ c
参数作用
location峰值位置（分布中心）
scale半区间宽度（区间 = location ± scale）
强制样本集中在 location 附近，波动较小。
指数分布 Exponential 连续

右偏分布，常用于模拟等待时间。

f(x) = (1/λ) × exp(-x/λ)
参数作用
location位置偏移（实际采样 = location + exp(scale) - scale）
scale速率参数的倒数 λ
产生非负偏态样本，适合建模时间间隔或强度。
伽马分布 Gamma 连续

右偏分布，形状参数由 scale 控制。

f(x) = x^(k-1) × exp(-x/θ) / (Γ(k)θ^k)
参数作用
location位置偏移
scale影响形状参数 k（k = 2 + |location|/scale）
适合建模非负的连续量，如收入、时间等。
贝塔分布 Beta 有界

在 [0,1] 区间内的分布，适合建模比例。

f(x) = x^(α-1)(1-x)^(β-1) / B(α,β)
参数作用
location映射到 [0,1] 区间的中心
scale控制分布的集中度
输出被限制在 [location-scale, location+scale] 范围内。
泊松分布 Poisson 离散

离散计数分布，用于建模事件发生次数。

P(X=k) = (λ^k × e^(-λ)) / k!
参数作用
location对数发生率（rate = exp(location)）
scale调整发生率的范围
输出是整数，适合计数数据，散点图会呈现阶梯状。

5. 使用示例

5.1 预设模型说明

预设名称 配置特点 适用场景
三元高斯基线 所有变量使用正态分布，中等 scale 默认配置，适合首次运行
厚尾鲁棒链 Student-t + Laplace + Normal 观察极端值对链的影响
有界比例混合 Beta + Triangular + Uniform 观察边界内的波动
偏态过程 Exponential + Gamma + Logistic 建模非对称过程
计数混合链 Poisson + Normal + Laplace 包含离散计数变量
强相关压力测试 高系数 (0.8, 0.6) 观察强相关性下的链混合

5.2 诊断解读指南

  • 质量 = "优秀"：ESS > 45% 的总样本数，链混合良好
  • 质量 = "可用"：ESS 在 20%-45% 之间，可接受但建议增加采样
  • 质量 = "偏低"：ESS < 20%，建议增加 thinning 或延长迭代
  • 强相关 (>0.75)：变量间存在强线性关系，链可能收敛较慢

5.3 实践建议

调试技巧： 如果链不稳定，可以尝试：
  • 降低条件系数（减少变量间依赖）
  • 减小 scale（减少每次跳跃的幅度）
  • 增加 burn-in（给链更多时间收敛）
  • 使用 thinning（减少样本自相关）
